# P0 · asset-probe（资产存活探测工具）

基于 Go 语言开发的并发资产存活探测 CLI 工具。
本项目是「Go × 网安 12 个月双线计划」的第一个里程碑（P0），旨在跑通“写代码 → 构建 → 运行 → 看结果”的完整链路，并掌握 Go 并发控制的核心基础。

## ✨ 功能特性
- **高并发控制**：基于 Worker Pool（生产者-消费者模型）架构，通过 `-c` 参数精确控制并发数，已实测 100+ 目标并发不崩溃。
- **请求伪装**：自定义 HTTP User-Agent（伪装为 Chrome 浏览器），绕过基础 WAF 拦截。
- **超时重试**：支持配置单个请求超时时间（`-t`）与失败重试次数（`-r`），有效处理网络抖动和 5xx 错误。
- **信息提取**：自动抓取响应状态码、`Server` 头以及网页 `<title>`。
- **结果落盘**：将探测结果写入 `results.csv`，自带 UTF-8 BOM，Windows Excel 打开无中文乱码。
- **异常防崩**：遇到 DNS 解析失败、连接拒绝、读取超时等异常时，不中断程序，优雅记录错误信息。
